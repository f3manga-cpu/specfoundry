SPECFOUNDRY / INDEPENDENT HUMAN REVIEW

Agent Action Surface Snapshot.

A bounded engineering review that identifies potential external-action code paths and turns them into a short, prioritized verification plan. It is intended for teams preparing to let autonomous agents take consequential actions.

Included in one review

  • One agreed public GitHub repository and one AI-agent workflow, up to 200 selected source files.
  • Read-only action-surface inventory with file paths, line numbers and classified patterns.
  • Concise 1–2-page written note: up to five prioritized questions or control checks with rationale and next steps.
  • Written handoff by email with clear scope, known gaps and unresolved assumptions.

Not included

No penetration testing, live production access, automated enforcement, complete vulnerability discovery, secrets handling, compliance certification, or guarantee that an agent is safe.
